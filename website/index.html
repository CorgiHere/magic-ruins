遊戲規則說明　·　累計 3 次犯規抽道具

玩法說明

  • 根據右圖站位置
  • 安全棍上有貼地膠，請依指示遊玩
  • 若有嚴重違反計犯規 1 次
  • 中間四人依序一左一右
  • 遊玩過程碰到左右壁，繼續遊玩
  • 發揮默契　讓棍子成為堅強盾牌

犯規說明

  1. 若手遠離膠帶太遠 *1
  2. 不可超出前後的線 *1
  3. 不可將球擊至髖以上 *1
  4. 若爆頭對方 *2
  5. 若守門員逾 3 秒未開始，球權交換
  6. 累計 3 次犯規，對方可抽道具

注意事項

  • 請用足部內側踢球
  • 盡量不要用腳尖、腳背
  • 每一排人可同時左右移動
  • 多多溝通保持順暢
  • 兩側卡球時由守門員開球
  • 戴眼鏡的人請特別注意安全
